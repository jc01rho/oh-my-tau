## 2. Why TypeScript is being dropped

The rationale is entirely in `PHILOSOPHY.md` - **the README never argues it**, it only records the Rust outcome plus one npm shim. Four distinct arguments:

1. **Idiom convergence (the primary reason)** - `PHILOSOPHY.md` > `## The two bets` > **2**: *"Agents average the training corpus; TypeScript hands every codebase its own dialect, Rust rejects the unsound version before it runs. 'Pick a language your agents can't ruin.' Mediocre-but-uniform beats brilliant-but-divergent."* Because agents are both builders and users, a language with high per-repo variance multiplies agent error; Rust's compiler is a uniform gate.
2. **Performance / removing compensations** - `PHILOSOPHY.md` > `## Standards` > **Performance is correctness**: *"'ts is slow, rust isn't' — the rewrite exists to delete the throttles, GC workarounds, and UTF-16 defenses that compensated for the runtime, not to port them. 50 ms is a lot."*
3. **Ported-code corollary** - `AGENTS.md` > `### Porting (from pi)` > **2**: copy Pi's tests, but "drop TS-shaped compensations (throttles, GC workarounds, UTF-16 defenses)"; port behavior, not shape; reimplement where the shape is wrong (mermaid, slopjson, brush parser); never wrap what should be native.
4. **Extension runtime replacement, not just host language** - `AGENTS.md` > `### Locked Deviations from pi`: *"Extensions/eval: embedded free-threaded CPython only — no JS/TS plugin runtime, no multi-language eval; stdlib frozen in-binary."* Justification for Python-over-TS is in `PHILOSOPHY.md` > `## The eight lessons` > **1 The Stack**: "agents write decent Python, it embeds small, and it can introspect itself."

Residue that is *deliberately* kept: `PHILOSOPHY.md` > `## Rust, specifically` and `AGENTS.md` note model-facing edit error strings stay byte-identical to the TypeScript implementation because models were trained on those messages (`/tmp/oh-my-pi-omp2/crates/edit/README.md` line 5); and `/tmp/oh-my-pi-omp2/README.md` > `### Top level` keeps `npm/pi-coding-agent` as a distribution shim. TypeScript also survives as a *target language of the edited code* (lint rules in `crates/driver/src/rules/builtin/ts-*.md`), not as the implementation language.
